# LaTeX Suite
#数学 
**快速补全数学公式，自定义内容替换**
1. 自动补全 $\LaTeX$ 数学代码
	内置大量数学环境与命令的补全规则。比如打 $1/2$ 自动变成 $\dfrac{1}{2}$， ……内置的补全规则涵盖各种常见数学符号（积分，算符），希腊字母等等。
2. 自定义 trigger
	顾名思义，可以定义触发关键字及其展开内容。比如你让它输入 44 就变成 \$\$，打 part 变成 $\dfrac{ \partial y }{ \partial x }$。 还可以往里面塞各种数学符号。

VSCode 也有相似插件。

# Notebook Navigator
#界面 #效率
**把 Obsidian 变成 Notion 风格的双栏笔记库**
将 Obsidian 原生的左侧文件替换成类似 Evernote 或 Mac Finder 的双栏浏览体验。
1. 现代化的双栏布局
	彻底改变原本的交互。左边是文件夹和标签树，右边是当前选中目录下的笔记列表（支持显示摘要、封面图、修改时间）。
2. 支持类似 Iconize 的功能（修改文件夹图标），还支持自定义文件夹颜色。
3. 纯键盘流导航
	可以完全用方向键 `↑` `↓` `←` `→` 在文件夹、标签和笔记列表之间穿梭。
4. 强大的标签管理
	不只是简单的列出标签。它支持在侧边栏直接重命名标签（自动更新所有笔记）、拖拽合并标签、甚至可以通过 `Ctrl + Click` 进行复杂的标签组合筛选……*（当然这个功能我没用过）*

# Tasks
#任务管理 #效率
**把笔记变成真正的 GTD 任务中心**
Obsidian 自带的任务列表只是简单的复选框，而 Tasks 让它变成了专业的任务管理工具。
1. 全库任务聚合
	不用把任务都写在一个文件里。你在任何笔记里写下的 `- [ ] #todo 任务`，都可以用查询代码块聚合展示出来。比如“显示所有今天到期的工作任务”。
2. 强大的重复功能
	支持复杂的循环任务逻辑。比如“每两周的周五重复”、“完成后的 3 天再次提醒”，比很多专门的 Todo 软件还灵活。
3. 可视化操作
	不用手敲复杂的日期代码。点击任务后的日历图标，就能弹窗选择截止日期、优先级，甚至设置“开始日期”来过滤你不想看见的未来任务。

# Templater
#模板 #自动化
**从“复制粘贴”进化到“自动化生成”**
Obsidian 原生的模板功能太弱了，Templater 才是真正的“魔法师”。它允许你在模板里写 JavaScript 代码。
1. 动态插入内容
	不仅仅是插入固定文本。它可以自动填入“今天的日期”、“昨天的笔记链接”、“当前文件的标题”，甚至是你剪贴板里的内容。
2. 自动化工作流
	新建笔记时自动把文件移动到指定文件夹、自动根据日期重命名文件、或者一键插入当天的天气和名言。
3. 无限的扩展性
	因为它支持执行 JavaScript，所以理论上你想让它干嘛都行。比如写个脚本一键生成包含特定元数据的读书笔记框架，或者快速调用 API 获取信息。

# Calendar
#界面 #日记
**侧边栏的日历，日记党标配**
Obsidian 写日记必备的视觉化入口。它在右侧边栏挂一个小日历，不用去文件列表里翻翻找找了。
1. 点一下就写日记
	点击今天的日期，自动创建（或打开）当天的日记文件；点击过去的日期，直接跳转。再也不用对着文件名一个个对日期了。
2. 可视化“热力图”
	如果你设置了每日字数目标，日历上的圆点会根据你写的字数变大变小（或者变色）。看着日历被填满，成就感爆棚，绝对是坚持写日记的动力。
3. 周记支持
	不仅支持日记，开启设置后，点击左侧的周数，还能快速创建或跳转到“周记”，做周复盘非常方便。

# Excalidraw
#绘图 #可视化
**把最强的手绘风白板搬进笔记库**
这不仅仅是一个画图工具，它是打通“文字”与“图形”的神器。插件作者 Zsolt 把它做到了极致的深度集成。
1. 双向链接的视觉化
	别把它当成简单的画板。你可以按 `[[` 直接引用笔记，或者把左边的笔记文件拖进画布里变成一张卡片。点击画布上的元素就能跳转到对应笔记，这才是真正的“视觉笔记”。
2. 嵌入与实时更新
	画好的图可以直接用 `![[filename.excalidraw]]` 的语法嵌入到文档里。你在白板上改了一个线条，文档里的预览图自动同步更新，不用导出图片再重新粘贴。
3. 脚本与素材库
	支持安装各种脚本（Script）来自动化绘图，比如一键把层级列表转成思维导图。内置了海量的素材库，画 AWS 架构图、软件界面图，拖拽几下就搞定。
